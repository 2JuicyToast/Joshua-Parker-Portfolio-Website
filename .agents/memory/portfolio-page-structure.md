Each top-level portfolio navigation item should open its own page, using the shared header, visual format, and footer. Keep the Home page’s original introduction, ethical-innovation statement, skills, and quote on Home; map additional supplied content to its corresponding page instead of appending all sections to one long page. Use source-provided facts and mark genuinely missing information rather than inventing it.

**Why:** The user corrected an earlier single-page interpretation and supplied a Canva export with the original page content.

**How to apply:** When changing this portfolio’s navigation or content, maintain separate routes and preserve details from the user’s source material on the appropriate page.
